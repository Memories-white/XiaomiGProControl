# 验证记录与完成边界

> 汇总日期：2026-11-07。历史温度和转速只表示采样结果，不是持续压力测试。

## 测试分层

| 类别 | 工具 | 是否访问硬件 |
| --- | --- | --- |
| 协议测试 | `GProControl.ProtocolSmokeTests` | 否 |
| 合成日志 / 配置测试 | `GProControl.HardwareLogTests` | 否 |
| 本机遥测 | `GProControl.TelemetrySmokeTests` | 只读 |
| 服务探针 | `GProControl.ServiceProbe` | 依参数决定；`--hex`/`--wmi` 会提交请求 |
| 设备验证 | `GProControl.HardwareSmokeTests` | 依参数决定，部分测试会写入并恢复 |
| 灯效探针 | `GProControl.LightingProbe` | 默认只读，带 validate/restore 参数可能写入 |
| 安装验收 | `scripts/test-installer.ps1` | 安装系统集成；应用 smoke 模式跳过恢复写入 |

CI 构建主程序并运行协议、日志/配置、音频 DSP、报告隐私和链接的离线测试，不执行真机写入工具。

## 已记录的验证

### 0.12.4 服务、参数与音频频谱

详细参数本机读取 15 个分组，序列号报告排除与缓存检查通过。真实 WinUI：
`sections=15; links=6; serialHidden=True; rootBackHidden=True; navigation=True`。
灯效预设和主菜单导航回归通过。详细映射见 [服务与参数实现](service-and-details.md)。

音频 DSP 验证静音、DC 去除、PCM 16/24/32-bit、float 和扩展格式，以及 250/1000/4000 Hz 合成频率。
实际系统播放端点为 96000 Hz；低音量测试音 400 Hz 命中频段 6、4000 Hz 命中频段 13，均符合预期，
采样帧数分别达到 79680/196800。音频内容仅在内存处理，不写文件或上传。
麦克风选项已接入默认输入端点，本轮未主动验证麦克风采样。

动态灯效验证音量模式、频段混色、屏幕采样密度 1/5 的启动/停止；结束后原状态块及 RGB 数据恢复。
17 段频谱预览与统一 RGB 混色已实现，逐键频谱柱和逐键图像映射仍未开放。

0.12.4 安装/运行中覆盖/旧目录沿用/旧文件清理/非程序文件保留/旧布局迁移及卸载验收通过，
529 个程序文件完整性验证通过。用户配置、已有启动任务和原安装记录均保留。

### 0.12.3 原厂灯效预设

从原厂前端静态提取 12 个菜单入口与默认参数，新增预设卡片和恢复默认操作。

`cards=12; defaults=True; palettes=True; reset=True; hardwareWrites=False`。
协议、日志/配置和本机监控回归通过；光影随行/光音视界仍为基础统一色联动，
没有将预设入口齐全等同于完整复刻原厂逐键画面或频谱。

0.12.3 安装验收通过：运行中覆盖、原目录沿用、旧文件移除、非程序文件保留、
旧布局迁移、527 个文件校验、窗口/后台恢复及卸载；用户设置、开机任务和原安装记录保留。

### 传感器

管理员直接读取 `0x0900`，记录到：

```text
cpuTemp=90; gpuTemp=56; cpuFan=4707; gpuFan=4568
```

字段范围校验会拒绝无法解释的值。普通权限读取曾返回拒绝访问，应用因此需要管理员权限。

### 键盘灯效

```text
wave-roundtrip palette=2->0->2 direction=0->1->0
               brightness=3->0->3 speed=3->1->3 restored=True

power-off=verified
power-roundtrip=on->off->on restored=True
```

读取、写入、保存与恢复均使用 CMD 1/2/5，硬件版本由 CMD 6 检查。
回滚曾出现一次亮度延迟生效，已加入有限重试。配置测试覆盖旧版本兼容、关闭状态
保留波浪参数、重新加载和关闭恢复选项。
