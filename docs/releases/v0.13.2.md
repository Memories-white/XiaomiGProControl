# XiaomiGProControl v0.13.2 Preview / 预发布版

## 中文

- 在“我的服务 → 服务与反馈”新增“导出运行日志”。可将启动记录、操作结果及异常详情保存为文本文件，导出时会遮盖用户目录前缀。
- 补充灯效请求和键盘读回、性能模式、屏幕加速、设备开关，以及动态灯效异常的日志。
- 修复波浪、呼吸、贪吃蛇等常规灯效在键盘保留旧亮度时被回滚的问题。效果及其他适用参数读回正确时，应用并保存实际设置，在界面提示实际亮度。
- Windows x64 安装包为 `GProControl-0.13.2-Setup-x64.exe`，覆盖升级沿用原安装目录。可用 `SHA256SUMS.txt` 核对下载文件。

## English

- Added Export Runtime Log under My Services → Service and Feedback. Save startup events, operation results, and exception details as a text file. The export masks the user profile path prefix.
- Added logs for lighting requests and keyboard readback, performance mode, display overdrive, device switches, and dynamic lighting errors.
- Fixed a rollback affecting standard lighting effects such as Wave, Breath, and Snake when the keyboard retained its previous brightness. When the selected effect and its other applicable parameters are verified, the app saves the actual settings and displays the brightness reported by the keyboard.
- The Windows x64 installer is `GProControl-0.13.2-Setup-x64.exe`. In-place upgrades reuse the installation directory. Use `SHA256SUMS.txt` to verify the download.
