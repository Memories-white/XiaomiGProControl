# XiaomiGProControl v0.12.4 Preview

- New **Detailed specifications** page: machine, BIOS, CPU, GPU, memory modules, physical disks, displays and Windows.
- New **My services** page: official manual, service policy, locations, support, B21 drivers, Xiaomi account and project feedback.
- Copy parameter reports and diagnostic summaries. Device serial numbers are hidden by default and excluded from reports.
- Audio lighting: playback / microphone source, 17-band FFT preview, four original gradient palettes and uniform RGB frequency mixing.
- Adjustable screen sampling density; dynamic settings remain consistent when returning to the lighting page.

Validated with hardware specification reads, live playback frequency capture, lighting start/stop/restore,
real WinUI navigation and preset checks, and offline regression tests.

Keyboard output is still uniform RGB. Per-key screen mapping and keyboard spectrum bars remain unfinished.
Microphone capture was not exercised in this round. Official account, warranty and service transactions open in the browser.
