# XiaomiGProControl v0.12.2 Preview

A Windows 11-style control center for the **Redmi G Pro 2024 / TM2211**.
This is a prerelease for the tested hardware and vendor software versions.

## Download and install

- Download `GProControl-0.12.2-Setup-x64.exe` from the assets below.
- Requires **Windows 11 x64**, the vendor control center **2.1.1.418**, and **MiDeviceService 4.1.1.640**.
- The installer bundles .NET and Windows App SDK runtimes and requests administrator privileges before extraction.
- Existing installations are upgraded in place. Retired application files are removed using the owned-file inventory; settings and unlisted extra files are preserved.
- After an interactive installation or upgrade, you can choose whether to launch the app. The default is not to launch.
- `SHA256SUMS.txt` contains the installer checksum. This preview is not Authenticode-signed.

## Included functionality

- Four validated performance presets, CPU temperature, dual-fan readings, and local system/GPU monitoring.
- Fn, Windows key lock, and touchpad controls with firmware readback; GPU output mode with reboot notice.
- Twelve lighting modes: nine hardware effects, custom RGB lighting, and basic screen/audio-driven lighting.
- Saved lighting/performance restoration, a configurable close prompt, system tray operation, and optional elevated logon startup.
- Main-page navigation stays synchronized with the sidebar. Back navigation is reserved for explicit subpages.
- README translations: English, Simplified Chinese, Japanese, German, and Russian, with language links at the top.

## Validation and limits

The application build, offline protocol/settings tests, device-switch navigation regression, keyboard-effect
write/readback/restore tests, and screen/audio effect start/stop/restore checks have passed locally.
Installer validation covered install, upgrade while running, directory reuse, retired-file cleanup, legacy
inventory migration, application startup, background window restoration, and uninstall. Existing settings, startup tasks, and
installation registration were preserved during testing.

Screen/audio lighting currently drives a uniform keyboard color using the main-screen average or system
playback level. It does not reproduce the vendor's full audio spectrum or per-key image mapping.
Custom fan curves, fixed RPM, forced WLAN acceleration, and chassis lighting are not implemented.
Full Windows reboot restoration and broader device/version compatibility still need validation.

See [the validation record](https://github.com/Memories-white/XiaomiGProControl/blob/main/docs/verification.md)
for the detailed scope and [the README](https://github.com/Memories-white/XiaomiGProControl) for setup and research documentation.
