# XiaomiGProControl v0.13.0 Preview

- Per-key screen mapping across the vendor's 7×17 virtual keyboard matrix.
- Four-direction keyboard spectrum bars using the existing WASAPI/FFT capture and four original palettes.
- Live matrix preview, adjustable screen sampling density and saved output/direction settings.
- A reversible 16-second color-and-moving-bar check; per-key output stays off until the user confirms the physical display.
- CMD 4 frame output and CMD 0 heartbeat never persist animation frames to flash. Stopping restores the previous standard effect.

Packet/renderer tests, realtime-mode transport and restoration checks, six dynamic loops and WinUI controls checks passed.
Individual key colors cannot be read back independently; physical color/location verification still requires observation.
This preview does not claim pixel-identical reproduction of the vendor renderer. Chassis lighting remains outside this keyboard update.

Download `GProControl-0.13.0-Setup-x64.exe`; verify against `SHA256SUMS.txt`.

安装后进入“灯效 → 光影随行 / 光音视界”，先执行“校验逐键灯效（16秒）”。
确认实际分区和光带正常后，可选择“逐键映射 / 频谱柱”并应用。
