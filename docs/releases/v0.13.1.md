# XiaomiGProControl v0.13.1

## 中文

- 设备概览右上角新增“详细参数”入口。详细参数作为二级页面，支持返回设备概览。
- 硬件参数按类别展示为卡片，窗口较宽时显示双列，较窄时自动切换为单列。
- 首次安装和覆盖升级在向导最后一页提供“启动 G Pro Control”复选框，默认不勾选。勾选后点击“完成”即可启动。
- 下载 `GProControl-0.13.1-Setup-x64.exe`。覆盖安装沿用原安装目录。可用 `SHA256SUMS.txt` 核对安装包。

## English

- Open Detailed Specifications from the top right of Device Overview. The page is a subpage with a Back button to return to the overview.
- Hardware specifications appear in grouped cards. The layout adapts from two columns in wide windows to one column in narrow windows.
- Fresh installations and interactive upgrades offer a Launch G Pro Control checkbox on the final wizard page. It is unchecked by default. Select it and click Finish to launch the app.
- Download `GProControl-0.13.1-Setup-x64.exe`. Upgrades reuse the existing installation directory. Verify the download against `SHA256SUMS.txt`.
