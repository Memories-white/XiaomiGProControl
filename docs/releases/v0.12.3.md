# XiaomiGProControl v0.12.3 Preview

Factory lighting presets for Redmi G Pro 2024 / TM2211.

- Twelve preset cards in the original menu order, with factory defaults and reset controls.
- Seven solid colors and three gradient palettes, shown with color swatches.
- Correct zero-based width/length controls for Wavelet, Color Wave, and Snake.
- 65 hardware readback checks passed and the original keyboard state was restored.
- Actual WinUI preset loading, palette lists, and reset checks passed.

Screen and audio effects still use basic uniform-color linkage. Original per-key screen mapping
and full audio spectrum rendering remain unfinished. Requires compatible vendor drivers/service.

Download `GProControl-0.12.3-Setup-x64.exe`; verify against `SHA256SUMS.txt`.
