# XiaomiGProControl v0.13.3

## 中文

- 设备概览等待开机性能模式恢复完成后再读取固件，修复自启动时可能先显示「均衡」的问题。
- 设置新增网络速率单位。设备概览的上传和下载可以在 Kbps 与 MB/s 之间切换，重启后保留选择。
- 切换到混合输出时，确认弹窗会提示重启后 Intel 核显驱动可能需要几分钟才能就绪。期间内屏分辨率、刷新率和任务管理器中的 GPU 列表可能暂时异常。
- 改进键盘动态灯效的首帧反馈、暗场处理和关闭后的状态回读。
- 继承预发布版的运行日志导出功能，可在「支持」页面保存日志，方便反馈问题。

下载 `GProControl-0.13.3-Setup-x64.exe` 安装。覆盖安装沿用原目录，可用 `SHA256SUMS.txt` 校验下载文件。

## English

- The overview waits for startup performance-mode restoration before reading the firmware, addressing an incorrect Balanced status after automatic launch.
- Network speed units are configurable. Upload and download rates can use Kbps or MB/s, and the setting persists across restarts.
- The hybrid-output confirmation explains that the Intel graphics driver may take a few minutes to become ready after restarting. The built-in display's resolution or refresh rate and Task Manager's GPU list may be temporarily affected.
- Improved first-frame feedback, dark-frame handling, and state readback after stopping dynamic keyboard lighting.
- Runtime log export from the preview release is available on the Support page for troubleshooting.

Download `GProControl-0.13.3-Setup-x64.exe`. In-place upgrades reuse the existing installation directory. Verify the download with `SHA256SUMS.txt`.
