## English

- Added the factory **GPU Acceleration Engine**. Enabling the GPU overclock preset requires AC power, Full Speed mode, and confirmation.
- Fixed intermittent GPU state readback timeouts and switch flicker. The switch holds the requested position and stays locked until the target state is confirmed. If the readback times out, use the refresh button to check again.
- Reorganized the Performance page. The four EC presets sit above responsive cards for GPU acceleration, graphics output, screen acceleration, and WLAN status. Preset controls and the GPU confirmation dialog follow the active theme.
- Dashboard bars now animate their fill width while keeping the left edge fixed.

Download `GProControl-0.13.26-Setup-x64.exe`. Verify the installer with `SHA256SUMS.txt`.
